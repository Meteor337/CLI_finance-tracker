# Документация к приложению "CLI Finance Tracker"

Это документация для консольного трекера личных финансов, написанного на C++ (C++20/C++23). Документация предназначена для пользователей и разработчиков, желающих понять структуру и функциональность программы.

## Обзор приложения

Приложение представляет собой монолитный консольный утилитарный инструмент (CLI), управление которым осуществляется через аргументы командной строки (`argc`, `argv`).

**Основные механики включают:**
* Добавление транзакций (доход/расход) с указанием суммы, категории и комментария.
* Автоматическую генерацию уникальных идентификаторов (ID) на основе микросекундного системного времени (`<chrono>`).
* Автоматическую подстановку текущей даты в формате `YYYY-MM-DD`.
* Безопасную обрезку слишком длинных комментариев с поддержкой кодировки UTF-8.
* Просмотр отформатированной таблицы всех записанных операций.
* Расчет общего финансового баланса (суммарный доход, расход, профицит/дефицит).
* Сводную статистику расходов и доходов с группировкой по категориям.
* Автоматическое чтение и сохранение данных в CSV-файл (`data.csv`).

Для сборки и запуска приложения необходимы:
* Компилятор C++ с поддержкой стандарта **C++20** или выше (например, `g++` версии 13+ или `clang++`).
* Система сборки или возможность вызова компилятора из терминала.
* Операционная система с поддержкой консольных приложений (Linux, macOS, Windows).

## Установка и запуск

1. Склонируйте репозиторий или скачайте исходный код:
   ```bash
   git clone [https://github.com/your-username/CLI_finance-tracker.git](https://github.com/your-username/CLI_finance-tracker.git)
   cd CLI_finance-tracker

```

2. Скомпилируйте код с помощью компилятора C++:
```bash
g++ -std=c++23 main.cpp -o CLI_finance_tracker

```


3. Запустите приложение с нужной командой:
* **Вывод справки:**
```bash
./CLI_finance_tracker help

```


* **Добавление операции:**
```bash
./CLI_finance_tracker add --type "+" --amount 50000 --category "Стипендия" --comment "За сентябрь"

```


* **Просмотр списка всех транзакций:**
```bash
./CLI_finance_tracker list

```


* **Просмотр баланса:**
```bash
./CLI_finance_tracker balance

```


* **Просмотр статистики по категориям:**
```bash
./CLI_finance_tracker stats

```

## Основные компоненты

Приложение построено по монолитной архитектуре в одном файле и состоит из следующих ключевых слоев:

* **Диспетчер команд (`main`):** Точка входа, парсящая аргументы командной строки и вызывающая соответствующий обработчик.
* **Файловый слой (`loadFromFile` / `saveToFile`):** Чтение и сохранение данных в файл CSV.
* **Обработчики CLI-команд:** Вынесенные функции для обработки логики каждой команды (`handleAdd`, `handleList`, `handleBalance`, `handleStats`).
* **Модуль форматирования и UTF-8:** Вспомогательные функции для работы с байтами UTF-8 строк и выравнивания консольных таблиц.

## Структура данных

### Структура `Transaction`

Хранит полную информацию об одной финансовой операции:

```cpp
struct Transaction {
    long long id;        // Уникальный ID (microsecond timestamp)
    double amount;       // Сумма операции
    std::string category;// Категория (например, "Еда", "Транспорт")
    std::string date;    // Дата в формате "YYYY-MM-DD"
    std::string type;    // Тип транзакции ("+" — доход, "-" — расход)
    std::string comment; // Описание операции (опционально)
};

```

---

## Основные функции

### `generateUniqueId()`

Генерирует уникальный числовой идентификатор на основе текущего системного времени в микросекундах (`std::chrono::system_clock`).

### `truncateUTF8(const std::string& str, std::size_t max_chars)`

Корректно подсчитывает количество видимых UTF-8 символов (учитывая multi-byte кириллицу) и обрезает строку до указанного лимита, предотвращая битые байты и расползание консольных таблиц.

### `saveToFile(const std::string& filename, const std::vector<Transaction>& transactions)`

Записывает весь вектор транзакций в CSV-файл с разделителем `;`.

### `loadFromFile(const std::string& filename)`

Считывает данные из CSV-файла, пропускает заголовок и возвращает вектор структур `Transaction`. Содержит обработку исключений при парсинге поврежденных строк.

### `handleAdd(...)`

Парсит флаги `--amount`, `--category`, `--type`, `--comment`, определяет текущую дату, формирует новую транзакцию и сохраняет её в файл.

### `handleList(...)`

Форматирует и выводит в консоль аккуратную таблицу всех сохраненных операций.

### `handleBalance(...)`

Подсчитывает и выводит суммарный доход, расход и итоговый баланс с вердиктом (Профицит/Перерасход).

### `handleStats(...)`

Группирует операции с помощью `std::map<std::string, double>` и выводит раздельный отчет по расходам и доходам для каждой категории.

## Формат хранения данных

Данные сохраняются в текстовый файл `data.csv` в корневой директории программы. Разделителем колонок выступает символ `;`.

Пример содержимого `data.csv`:

```csv
ID;Тип транзакции;Сумма;Категория;Дата;Комментарий
1790094076399465;+;10000.00;Зарплата;2026-09-22;Выдали зарплату
1790095676109396;-;350.00;Еда;2026-09-22;Обед

```

> **Важно:** Не редактируйте разделители внутри файла вручную, чтобы избегать ошибок считывания структуры.
